# Benchmarking

Benchmarks are evidence and regression checks, not proof.

MathGraph records benchmark suites, cases, runs, and results so formal-world
workbenches can track practical robustness across proof finders, model finders,
finite checkers, and importers.

The ETP implication matrix is treated as benchmark/evaluation data. It is not a
certificate by itself. A row becomes terminal only when a verifier supplies a
verified proof, finite countermodel, or named obstruction certificate.

No-model-found is not proof. No-proof-found is not refutation.
