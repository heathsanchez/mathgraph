Terminal truth remains verifier-bound:

- `VERIFIED_PROOF` requires proof verification.
- `FINITE_COUNTERMODEL` requires finite-checker-backed source-holds /
  target-violates evidence.
- `NAMED_OBSTRUCTION` records a named residual/continuation obstruction.

Everything else is advisory, diagnostic, or provenance-limited.
