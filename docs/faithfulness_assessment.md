# Faithfulness Assessment

Shallow semantic embeddings are powerful because they let an object logic use a
strong host logic. They also create artifact risk: a host theorem is not
automatically a target-theory theorem.

`FaithfulnessAssessment` records bridge evidence for a specific embedding:
status, soundness status, completeness status, benchmarks, proof artifacts, and
counterexamples found.

A faithfulness assessment may support lower embedding risk when it is
mechanized, proved on paper, or empirically supported with soundness and no
counterexamples. It does not prove arbitrary imported claims.

MathGraph keeps proof authority attached to explicit terminal artifacts:
verified proofs, finite countermodels, or named obstructions.
