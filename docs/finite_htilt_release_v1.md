# Finite H-Tilt Verified Theorem Tower v1

This release records a three-layer verified theorem tower for finite H-Tilt
survivor laws.

## What is verified

1. Conditional generator-style survivor stationarity from assumed left/right
   modes.
2. Conditional discrete Doob row-stochasticity and a positive normalized
   stationary distribution under explicit mode and positivity hypotheses.
3. Positive-mode existence for finite irreducible nonnegative matrices through
   a quarantined exact-pin Perron–Frobenius portal.

## What remains outside the boundary

The release does not contain a killed-generator bridge, convergence,
ergodicity, mixing, a spectral gap, empirical h-band evidence, consciousness
evidence, or scheduler-performance evidence.
