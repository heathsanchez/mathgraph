# Formal Worlds

A formal world is a metadata boundary around an object language, identity policy,
denotation policy, verifier policy, semantic embedding metadata, and allowed
continuations.

Formal worlds are not possible-world metaphysics yet and are not proof objects.
They answer operational questions:

- Which object language is this claim written in?
- What counts as identity in this domain?
- Which terms are safe to denote?
- Which verifier has authority?
- Which semantic embedding risks are visible?
- Which continuations are blocked before construction?

The current presets are:

- `formal_world_etp_magma`: the ETP magma equational implication nursery.
- `formal_world_aot_precedent`: AOT / computational metaphysics metadata only.

Formal worlds encode admissible propositions and safety policies. They do not
promote claims to truth.
