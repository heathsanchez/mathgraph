# Interpretation Choice Points

Formal-world imports often contain choices: what a symbol denotes, what
“world” means, what “root” means, or how a theorem statement maps into typed
MathGraph objects.

`InterpretationChoicePoint` records candidate readings, selected readings,
rejected readings, downstream effects, and resolution status.

Making choices explicit prevents silent collapses. Same truth value is not same
continuation, and same extension is not same law.
