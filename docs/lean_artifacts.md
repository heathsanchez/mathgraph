# Lean Artifacts

MathGraph can now store Lean theorem/proof metadata and emit conservative Lean
skeletons for lemma candidates. It does not run Lean, require Mathlib, or claim
that generated sketches are verified.

Generated skeletons are marked:

```lean
/-!
Generated by MathGraph.
This file is not authoritative until checked by Lean.
-/
```

Lean artifacts become authoritative only when their verification status is
explicitly `LEAN_VERIFIED` or imported as verified with safe trust/provenance.
A Lean sketch is not Lean verification.
