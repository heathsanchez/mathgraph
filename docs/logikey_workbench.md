# Formal Workbench

MathGraph records lightweight formal-workbench metadata without importing
foreign theories or treating metadata as verification.

The layer records:

- L0 meta-logical substrate objects;
- L1 formal worlds, logics, and embeddings;
- L2 domain theories, lawbooks, and certificate corpora;
- L3 applications, episodes, schedulers, and middleware.

Workbench metadata is operational scaffolding. It helps MathGraph compare
embedding strategies, backend profiles, benchmark suites, and lifecycle state.
It is not a verifier and it never promotes a claim.

Truth boundary: verifiers decide terminal forms. Workbench rows, root pressure,
reason clusters, benchmark passes, and scheduler pressure are advisory unless
backed by concrete verified proof, refutation, or obstruction certificates.
