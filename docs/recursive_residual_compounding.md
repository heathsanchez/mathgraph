# Recursive Residual Compounding

This benchmark is the stronger ETP/SAIR compounding path. It starts with a
generic finite-countermodel route, records the residual frontier, mines
additional constructor candidates from that frontier, and evaluates whether a
compact constructor atlas transfers to held-out pairs.

The compact atlas is advisory route memory. It does not verify claims. A
residual-mined constructor becomes terminally useful only when a finite checker
uses it to produce a concrete countermodel certificate and that certificate
passes the PromotionGate/Lawbook boundary.

## Pipeline

```text
generic finite-countermodel route
-> residual frontier
-> residual-mined constructor candidates
-> recursive generations
-> constructor attribution
-> compact atlas routes
-> held-out transfer controls
-> gate report
```

## Running Fallback Smoke

```bash
python scripts/run_recursive_residual_compounding.py \
  --profile smoke \
  --allow-fallback-demo \
  --out-dir /tmp/mathgraph_recursive_residual_smoke
```

Fallback mode proves wiring only. It must not be interpreted as real SAIR
performance.

## Running Real ETP/SAIR

```bash
python scripts/run_recursive_residual_compounding.py \
  --equations /content/equations.txt \
  --matrix /content/etp_matrix_full_best_bool.npy \
  --profile fast \
  --generations 5 \
  --seed 1729 \
  --out-dir /tmp/mathgraph_recursive_residual_fast_real
```

## Interpreting Metrics

- `generic_recoveries`: held-out FALSE pairs recovered by the base route.
- `recursive_full_recoveries`: held-out FALSE pairs recovered after residual
  mining.
- `best_compact_recoveries`: held-out FALSE pairs recovered by the best compact
  atlas route.
- `true_contamination_count`: TRUE controls incorrectly separated by the route.
  This must stay zero for the route being evaluated.
- `oracle_gap_captured`: fraction of recoverable gap closed when an oracle
  reference is available.

## Boundary

Residual-mined constructors, compact atlases, Reason Atlas entries, and route
scores are advisory. They may guide future checker attempts. They cannot emit
`TRUE`, `VERIFIED_PROOF`, `FINITE_COUNTERMODEL`, or `NAMED_OBSTRUCTION` by
themselves.
