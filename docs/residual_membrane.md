# Residual Membrane

Residuals are membranes. Roots are phase gates. Discovery is representational crossing.

## Core Terms

**Residual Membrane**: the boundary of unresolved cases left after current
constructors, routes, and certificates are exhausted. It is not backlog. It is
where the current language stops being sufficient.

**Viability Ridge**: a structured high-pressure path along the residual membrane
where unsolved cases remain nameable, near-solvable, and capable of revealing
roots.

**Representation Elevator**: the up/down movement from concrete failed cases
into motifs, obstructions, quotient geometry, and invariants, then back down into
constructors and certificates.

**Phase Gate**: a root-node location where changing representation converts
stubborn residuals into constructible certificates or named obstructions.

**Root Spine**: a connected chain of persistent roots along a viability ridge.

## Distinction

- residual membrane = where current language fails
- viability ridge = where failure is structured and fertile
- root node = where many failures compress
- phase gate = where new abstraction opens
- representation elevator = up/down traversal
- constructor = descent path
- certificate = stabilized crossing
- lawbook = remembered transformation

## Truth Boundary

Residual membrane analysis is advisory. A membrane, ridge, phase gate, or root
spine does not prove or refute any claim. Only terminal certificates can cross
the truth boundary.
