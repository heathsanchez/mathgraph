# Root Node Discovery Doctrine

Root nodes are not found by generating more successes. They are revealed by
studying where successful continuation fails.

The stubborn residual is not the enemy. It is the instrument.

MathGraph’s root-discovery layer treats the final residual surface after high
coverage as a selection surface. SAT rows show where continuation exists. UNSAT
rows show where continuation is blocked. UNKNOWN and TIMEOUT rows show where
pressure is needed. ERROR rows show brittle route evidence. None of this
telemetry is wasted.

## Search Versus Discovery

Search asks for another model, proof, or certificate.

Discovery asks why one narrow obstruction surface suddenly starts producing
reusable certificates while nearby surfaces stay blocked.

A root is not a frequent motif. A root is a persistent, non-shadow,
load-bearing continuation point whose resolution compresses residuals and
produces reusable certificate families.

Same coverage is not same reason. Same table behavior is not same root. Same
extension is not same law.

## Why Stubborn Residuals Matter

Residuals are pressure fields, not leftovers. Repeated failure is obstruction
geometry. When current constructors, tables, motifs, and routes stop explaining
the problem, the residual tells MathGraph where its next concept must be cut.

Root nodes are SAT-clusters carved out by UNSAT boundaries. A high-support
all-SAT cluster can be useful, but without a boundary it may be only a shadow
of a deeper support pillar.

## Full Cycle

```text
certificate universe
-> telemetry universe
-> residual surface
-> persistent filtration
-> shadow collapse
-> effective filtration count
-> root promotion
-> root compiler
-> constructor family
-> replay/elevation
-> lawbook update
-> sharper residual
```

Derived closure is compounding, not verification. The lawbook becomes stronger
only when terminal artifacts cross the existing verifier/importer boundary.

## Truth Boundary

Root discovery is advisory. It may produce root candidates, obstruction
candidates, constructor-family plans, route-pressure updates, and replay queues.
It must not claim terminal truth.

Only importer-revalidated finite countermodels, chain-audited derivations, or
formal proofs may cross the terminal truth boundary.
