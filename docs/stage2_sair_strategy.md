# Stage 2 SAIR Strategy

SAIR Stage 2 is certificate production, not classification. The known public
shape is 4,694 equations and a 4,694 x 4,694 implication matrix with true rate
approximately 0.371172.

For MathGraph, the competition is a nursery for the general certificate
factory:

- FALSE certificate = finite magma table satisfying EQ1 and violating EQ2.
- TRUE certificate = proof, eventually Lean proof.
- Finite search failure is not proof of TRUE.

## Practical Loop

1. Audit and preserve all existing certificates.
2. Build a primitive certificate ledger.
3. Apply derived certificate closure.
4. Identify the residual membrane.
5. Replay paths toward 99.94% coverage without treating coverage as proof.
6. Extract support pillars.
7. Split the residual by named obstruction.
8. Build basin-specific constructors.
9. Export certificate artifacts and audit chain.
10. Keep unverified cases as residual or named obstruction.

## Boundary

Matrix truth can guide distillation, but it is not a certificate. Every scoring,
route, motif, and residual label remains advisory until a verifier produces a
terminal certificate and the importer/audit boundary accepts it.
