# Curated Real Mathlib Demo Examples

The curated example files are templates only. Supply an already-existing local project path; MathGraph will not clone, download, or resolve dependencies.

For repo-local smoke tests, use `synthetic_standin_real_mathlib_demo_config.json` with `--project-root examples/mathlib_micro_subset`. It intentionally names `Mathlib/MathGraph/*.lean` fixture modules rather than real Mathlib modules.
