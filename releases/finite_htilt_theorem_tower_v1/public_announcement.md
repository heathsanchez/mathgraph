# Public announcement draft

MathGraph has released its first full verified theorem tower.

The release, `finite-htilt-theorem-tower-v1`, turns a speculative H-Tilt
survivor-law idea into three bounded Lean-verified layers:

1. conditional survivor algebra for a generator-style Doob transform;
2. conditional discrete Doob stationarity and row-stochasticity;
3. a Perron–Frobenius discrete portal proving positive normalized stationary
   survivor distributions for finite irreducible nonnegative matrices.

The key survivor distribution is

$$
\pi^*_i = \frac{q_i h_i}{\sum_k q_k h_k}.
$$

The release is deliberately bounded. It does not prove a killed-generator
bridge, Markov convergence, ergodicity, mixing, empirical h-band universality,
consciousness, or scheduler performance.

The main achievement is not a broad interpretive claim. It is the MathGraph
loop itself:

```text
speculative theory
→ claim decomposition
→ exact kernel extraction
→ Lean verification
→ external theorem portal
→ Lawbook
→ release tag
→ explicit non-claims
```
